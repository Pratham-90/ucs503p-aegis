# Final evaluation report

The LaTeX source of the final evaluation report, built on the TIET report class (`tietreport.cls`, v1.0.4).

- `main.tex`: the report
- `tietreport.cls`: the TIET class, unchanged from the template
- `references.bib`: the bibliography (biblatex + Biber)
- `figures/`: the diagrams, and the screenshots captured by the end-to-end test on the final interface

To build the PDF, upload this folder as a zip to Overleaf and click **Recompile** (pdfLaTeX; Overleaf runs Biber automatically).
